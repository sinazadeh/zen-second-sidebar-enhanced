Second Sidebar

Web panels next to your tabs. Changes apply right away, in every window. Each panel has its own settings too: right-click its button and choose Edit web panel.

Second Sidebar isn't running in this window, so some of its settings can't be shown. Restart the browser after installing it, then reload this page.

Preview

Hover a panel button in the preview to see its tooltip.

Shortcuts and backup

Keyboard shortcuts and settings export and import are in the sidebar's own settings: right-click the sidebar and choose Sidebar settings.
